# Scientific Calculator

A scientific calculator that runs in the browser, built with plain HTML, CSS and JavaScript (no dependencies).

## Features

- Trig functions and their inverses, with a degree/radian toggle
- ln, log, eˣ, 10ˣ, powers, square and cube roots, reciprocal, factorial, |x|, %, π, e
- Live preview of the result while typing, plus an `Ans` key for the last answer
- History panel that is saved between visits
- Full keyboard support
- Light and dark themes

## Usage

Open `index.html` in any modern browser.

| Key | Action |
| --- | --- |
| `0-9 . + - * / ^ ( ) ! %` | Input |
| `Enter` / `=` | Evaluate |
| `Backspace` | Delete |
| `Esc` | Clear |
| `s` `c` `t` | sin / cos / tan |
| `l` `g` `r` `p` | ln / log / √ / π |
